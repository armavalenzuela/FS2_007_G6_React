Carpeta para las fotos de cada producto del catalogo.

Convencion de nombres: <codigo>.jpg (el mismo "codigo" que tiene el producto
en assets/Js/products-data.js), por ejemplo:

  TC001.jpg  -> Torta Cuadrada de Chocolate
  TC002.jpg  -> Torta Cuadrada de Frutas
  TT001.jpg  -> Torta Circular de Vainilla
  TT002.jpg  -> Torta Circular de Manjar
  PI001.jpg  -> Mousse de Chocolate
  PI002.jpg  -> Tiramisú Clásico
  PT001.jpg  -> Empanada de Manzana
  PT002.jpg  -> Tarta de Santiago
  PV001.jpg  -> Torta Vegana de Chocolate
  TE001.jpg  -> Torta Especial de Cumpleaños

Basta con guardar la imagen aqui con el nombre correspondiente: catalog.html
y products.html ya apuntan a "assets/img/productos/<codigo>.jpg" y la
mostraran automaticamente, sin tocar el codigo. Si el archivo no existe
todavia, se muestra el fondo rosado de respaldo en su lugar.
