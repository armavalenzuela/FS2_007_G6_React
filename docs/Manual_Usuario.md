# Manual de Usuario - Pastelería Mil Sabores

## 1. Ingreso
1. Abrir el frontend en `http://localhost:5173`.
2. Ir a Iniciar sesión.
3. Ingresar correo y contraseña. Usuarios demo: `admin@duoc.cl / admin123`, `vendedor@duoc.cl / vendedor1`, `cliente@duoc.cl / cliente123`.

## 2. Cliente
- Navegar catálogo, ofertas y detalle de producto.
- Agregar productos al carrito.
- Realizar checkout y revisar pedido.

## 3. Vendedor
- Ingresar al panel de productos.
- Visualizar listado y detalle de productos.
- Visualizar listado de pedidos.

## 4. Administrador
- Gestionar productos: crear, editar y eliminar.
- Gestionar usuarios y pedidos.
- Acceder a dashboard.
