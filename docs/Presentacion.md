# Presentación del Caso

## Estructura sugerida (15 minutos)
1. Introducción y requerimientos del cliente (2 min).
2. Backend Spring Boot: entidades, repositorios, servicios y controladores (3 min).
3. API REST y Swagger: endpoints CRUD y códigos HTTP (3 min).
4. Integración frontend-backend con Axios y flujo de datos (3 min).
5. Seguridad JWT, roles y restricciones de acceso (2 min).
6. Demo funcional y cierre (2 min).

## Preguntas probables
- ¿Cómo se conecta el backend a la base de datos?
- ¿Qué endpoints CRUD existen?
- ¿Cómo se documenta la API?
- ¿Cómo se integra React con Spring Boot?
- ¿Cómo funciona JWT y los roles?
- ¿Cómo se mantiene la sesión en el frontend?
